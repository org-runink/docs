            runi/toml

            runi/toml

            import "github.com/org-runink/runi/toml"

            Package toml reads TOML v1.0.0, the configuration format of model sampling files, tool manifests and frontmatter, into Go values.

            var cfg struct { Models []struct { Name string toml:"name" Temperature float64 toml:"temperature" Stop []string toml:"stop" } toml:"models" } err := toml.Unmarshal(data, &cfg)

            [Unmarshal] and [Decode] fill structs, maps, slices, arrays, pointers, interfaces and the basic types. [Parse] returns the document as a map[string]any. A [Decoder] with [Decoder.DisallowUnknownFields] refuses any key the destination struct has no field for, which is what strict decoding of a configuration file needs.

            Matching keys to fields

            A field’s key is its toml:"name" tag, or its Go name when it has none. Matching is case-sensitive, as TOML keys are: a key Temperature does not fill a field tagged “temperature”. toml:"-" skips a field, and options after a comma in the tag are ignored. Fields of embedded structs are promoted as encoding/json promotes them. Fields absent from the document keep the value they had.

            Types

            An integer fills any integer field it fits, and a float field when the float holds it exactly; a value that does not fit is an error, never a silent wrap or rounding. A float fills only a float field. A string fills a string field, or any type that implements encoding.TextUnmarshaler.

            An offset date-time becomes a time.Time. The three local kinds become [LocalDateTime], [LocalDate] and [LocalTime]; a local date-time or date may also fill a time.Time, which places it in UTC because the document names no zone. A local time cannot fill a time.Time.

            Errors

            Every problem with the document is an [*Error] carrying the line and column, and for a decoding problem the key path with array indexes:

            toml: servers[0].port: expected integer, got string (line 12:8)

            Defining a key or a table twice, appending with [[ ]] to an array written inline, and adding keys to an inline table after it closes are all rejected, as the specification requires. The error says where the first definition was.

            What this package is not

            It does not write TOML. It reads one complete document at a time from memory; a [Decoder] reads all of its reader first. It keeps whole seconds from 00 to 59: TOML allows a leap second, and time.Time cannot hold one as written, so second 60 is an error rather than a silent roll-over into the next minute. Fractions of a second finer than a nanosecond are truncated, which the specification permits. It implements TOML v1.0.0, not the later v1.1 additions: times must have seconds, inline tables stay on one line, and \e and \x escapes are errors.

            It does not expand environment variables or include other files; do that to the decoded values, where the rules are yours.

            Error 

            type Error struct

            Error is a problem with the document: a syntax error, a key or table defined twice, a value that does not fit its Go destination, or (with [Decoder.DisallowUnknownFields]) a key the destination has no field for.

            Line and Column are 1-based; Column counts characters, not bytes. Path is the key path the problem belongs to, with array indexes, such as servers[0].ports; it is empty for syntax errors.

            Defined in toml/errors.go.

            LocalDate 

            type LocalDate struct

            LocalDate is a TOML local date, such as 1979-05-27: a day on the calendar with no time and no time zone.

            Defined in toml/datetime.go.

            LocalDateTime 

            type LocalDateTime struct

            LocalDateTime is a TOML local date-time, such as 1979-05-27T07:32:00: a moment on a wall clock, in no particular time zone.

            Defined in toml/datetime.go.

            LocalTime 

            type LocalTime struct

            LocalTime is a TOML local time, such as 07:32:00.999: a time of day with no date and no time zone. Precision finer than a nanosecond is truncated.

            Defined in toml/datetime.go.

            Decoder.DisallowUnknownFields 

            func (d *Decoder) DisallowUnknownFields()

            DisallowUnknownFields makes Decode fail on any key that the destination struct has no field for, as strict decoding of a configuration file should: a misspelt key is then an error instead of a setting silently left at its default. Every unknown key is reported, each as an [*Error] with its path and position, joined into one error. Keys decoded into a map or an interface are never unknown.

            Defined in toml/decode.go.

            ErrInvalid 

            var ErrInvalid = errors.New("toml: invalid argument")

            ErrInvalid is matched, with errors.Is, by every error caused by a bad argument rather than by the document: a nil or non-pointer destination.

            Defined in toml/errors.go.

            Parse 

            func Parse(data []byte) (map[string]any, error)

            Parse reads a document into a map. Values are string, int64, float64, bool, time.Time (an offset date-time), [LocalDateTime], [LocalDate], [LocalTime], []any and map[string]any.

            Defined in toml/decode.go.

            Unmarshal 

            func Unmarshal(data []byte, v any) error

            Unmarshal reads a document into v, which must be a non-nil pointer. Keys with no matching struct field are ignored; use a [Decoder] with [Decoder.DisallowUnknownFields] to refuse them.

            Defined in toml/decode.go.
