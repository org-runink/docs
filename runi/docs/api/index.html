API Reference

API Reference

Every exported symbol in every package, generated from the source so it cannot drift from it. For the canonical reference, including example output and unexported detail, see pkg.go.dev.

Package What it does
runi/stats Describe, split and scale a column, and test whether a relationship is real
runi/arimax Forecast a series using the things that drive it
runi/season Find the season and the trend breaks, then split the series apart
runi/bm25 Rank documents by the words they share
runi/salvage Get JSON out of a language model's reply, without guessing
runi/avro Read and write Avro and Avro OCF files
runi/barn Append-only versioned tables with time travel, no database
runi/memo Memoise an expensive call, one allocation per miss
runi/lazy Compute once, on first use, safely under concurrency
runi/budget One deadline for a whole request, split across its phases
runi/chain Tamper-evident chaining and verification of records
runi/toon A compact object notation that costs fewer tokens than JSON
runi/toml Read TOML v1.0.0 configuration files into Go values, strictly if asked
runi/drift Streaming change detection over a moving baseline
runi/rate Cumulative counters into per-interval rates, across wraps and resets
runi/tree Subtree sums and maxima of a hierarchy, kept current
runi/sustain Threshold decisions that do not flap
runi/throttle Cap how often something acts
