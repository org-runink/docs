Documentation

Documentation

Runink River is an optimized developer workstation on s6. It is a DEsk desktop for data, analytics and AI development on hardware you own, built on:

  • s6 init (s6, s6-rc, s6-linux-init). Never systemd.
  • linux-runink, one kernel: the zen kernel 7.2.x stable series, built from signature-verified sources. The kernel and OpenZFS packages build for x86_64 and aarch64; the installer image and the [runink] repository are x86_64 only today.
  • An encrypted ZFS root (aes-256-gcm on every dataset) with boot environments.
  • A default-deny firewall and river-sandbox for code you do not trust.
  • A graphical, zero-knowledge installer that measures the machine, plans the disks and shows you the recovery key once.

The name is always written in full, "Runink River". A bare "River" is the name of an unrelated Wayland compositor. Package, path and binary names (runink-*, river-*, /etc/runink) are identifiers and keep their spelling.

Warning: Status: pre-release. There is no signed public release yet: the release-signing key is published, but no release has been cut with it. The first release ships only after it installs, reboots, unlocks its disk and reaches a working desktop on real hardware; that gate is still open. The ISO is still assembled with a fork of Artix Linux's ISO tooling and Artix packages. Runink River is migrating from Artix to official Arch Linux packages plus Runink River's own s6 layer (in progress, docs/ARCH-BASE.md); its own from-source base comes after that. See the roadmap.

Scope of the project

Runink River ships the operating system, its packaging and its installer. Applications and platforms are not part of it: a downstream distribution can build on Runink River, and does so outside this repository. The source, including every document these pages summarise, is at github.com/org-runink/river.
