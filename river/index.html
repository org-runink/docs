    RIVER · Raft-Integrated Validated Event Runtime

    Everything about the developer workstation on s6: how to install it, what every part does, and how to run it day to day. KDE Plasma, the linux-runink kernel, an encrypted ZFS root, a default-deny firewall and a graphical installer.

    Get started Product page on runink.org

    At a glance

    What it is
    A developer workstation operating system: KDE Plasma on s6 (never systemd), one pinned kernel, an encrypted ZFS root with boot environments, a default-deny firewall, a sandbox for untrusted code and a graphical installer.
    Who it is for
    Developers and teams who build data, analytics and AI software on machines they own and need to know exactly what runs there, and distributions that want an auditable base to build on.
    Why it matters
    Every upstream is pinned by version and checksum, the rules every change must keep are written down and checked in CI, releases are signed offline, and nothing in the image reports usage or calls a hosted service.
    Status
    Pre-release: no signed release yet. The first one ships only after it installs, unlocks and reaches a working desktop on real hardware. Roadmap
    Licence
    MIT by default; GPL-2.0-only kernel packaging and CDDL-1.0 OpenZFS packaging; every file mapped and checked with REUSE. Licensing
    Governance
    Open and written down: lazy consensus, a public vote as the fallback, a path from contributor to maintainer. Single-vendor today, one maintainer; foundation incubation is planned and nothing has been submitted. Governance & community
    Contribute
    Sign off every commit under the DCO (no CLA); ask in GitHub Discussions, report bugs in Issues. Contributing
    Security
    Report privately through GitHub private vulnerability reporting or security@runink.org; receipt acknowledged within 3 working days. Report a vulnerability
