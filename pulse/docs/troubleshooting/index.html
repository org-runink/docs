Troubleshooting

Troubleshooting

Find the message you see, then read the cause and the fix. Messages are quoted from the source; ... marks a part that varies.

The server will not start

Message Cause Fix
refusing to start: no session signing key configured (PULSE_JWT_SECRET unset) PULSE_JWT_SECRET is unset Set it to a new random value. There is no default and none is generated.
refusing to start: the pulse appfs root cannot be mounted: ... The sealed app root has no usable backend Check the object store settings, or PULSE_APPFS_DIR for a local root.
Failed to initialize database: ... Usually TIDDE_ENVELOPE_KEK is missing; PULSE's store refuses to open without it Ask Runink to set the key.
refusing to start in production: insecure configuration: ... PULSE_ENV=production and a check failed Fix each listed problem. For the CORS problem, set CORS_ALLOWED_ORIGINS to pinned origins (no wildcard); the backend serves no web bundle, so there is no same-origin exemption.
TLS misconfigured: set BOTH PULSE_TLS_CERT and PULSE_TLS_KEY (or neither) Only one of the two is set Set both, or neither.
MESH_MTLS=true but mesh identity unavailable: ... No mesh identity could be set up Provide MESH_ISSUER_URL and MESH_CA_CERT (preferred), or the older MESH_CA_CERT and MESH_CA_KEY; or turn off MESH_MTLS.
Server exits with no output, no log file Locally: pkill -f 'pulse-server serve' matches the shell running that command, so it kills your own session Stop the server by its PID instead.
address already in use A previous server holds the port Stop it by PID, then restart.

Signing in

Message Cause Fix
invalid credentials The break-glass admin's username or password is wrong, or no break-glass admin was seeded (people sign in with Google) Use the break-glass username, not an email. On a local server, start it with PULSE_ADMIN_PASSWORD.
authorization token is not provided The call had no bearer token Send authorization: Bearer <accessToken>.
invalid token: ... The token expired, or its session was signed out Sign in again.
a cookie session requires the x-pulse-csrf header and a trusted Origin A browser call authenticated by the session cookie arrived without the x-pulse-csrf: 1 header, or from an origin this deployment does not trust For a browser front end, add its origin to CORS_ALLOWED_ORIGINS exactly; a wildcard is never accepted.
token contains an invalid number of segments A script read .token; the field is accessToken Read accessToken.
Google sign-in: "not set up on this PULSE" (/auth/google answers not_configured) Google sign-in is off Set GOOGLE_CLIENT_ID.
Google sign-in: "Nobody can sign in with Google on this PULSE yet" (sso_closed) AUTH_ALLOWED_EMAILS is empty Add the allowed addresses.
Google sign-in: "… is not on this PULSE's list of people allowed to sign in" (not_allowed) The email is not on the allowlist Add it to AUTH_ALLOWED_EMAILS.
Google sign-in: "Google signed you in for a different app" (wrong_client) The ID token was issued to another OAuth client than GOOGLE_CLIENT_ID Use the web client's ID in GOOGLE_CLIENT_ID; the Android app asks Google for a token for that same client.
Android: "This copy of the app is not registered with Google yet" The Google project of GOOGLE_CLIENT_ID has no Android OAuth client for org.runink.pulse with the SHA-1 of the key the installed app is signed with Add one for each key the app is signed with.
license expired or invalid A configured licence failed verification Install a valid licence.
Log: AUTHENTICATION DISABLED — every request will be rejected as Unauthenticated This deployment's session key is one PULSE refuses to sign or verify with, so no token can be accepted Replace PULSE_JWT_SECRET with a fresh value that has never been committed to a repository, and restart.

AI features

Message Cause Fix
inference server is not running / model service is not ready — the inference server is not running No inference server, or it is still loading Check INFERENCE_REMOTE_URL or the local model files. Watch model_ready on /health.
the inference plane is at capacity and declined this request; nothing was generated — retry in a few minutes The server is busy Retry in a few minutes.
the model returned no content for ... The model produced an empty response Retry. Check the inference server's log.
still-image generation is not available: the image-generation tier was retired ... Still images and videos are not made from a prompt Make a document or a podcast, or make a short video from a piece's script (Short videos).

Site score and audit fixes

Message Cause Fix
could not read ... — a reachable website with readable content is required to run the diagnostic PULSE could not load the site Check the URL is public and returns readable HTML.
url is required / repo_path is required A field is missing in ApplyAuditActions Fill it in.
apply modes are disabled on this server; set PULSE_APPLY_ENABLED=true (exactly, lowercase) and PULSE_AUDIT_APPLY=true to allow write/commit/pr The kill switch or PULSE_AUDIT_APPLY is off Use plan, or have an admin arm both.
apply modes require an administrator Your role is not admin Ask an admin to apply the fixes.
repo_path is not an allowed repository on this server The path is outside PULSE_APPLY_ROOT, missing, or escapes it Use a checkout inside the root.
audit apply has no repository root on this server; an administrator must set PULSE_APPLY_ROOT PULSE_APPLY_ROOT is unset Set it to the directory holding site checkouts.
github integration is missing a target owner/repo — ... pr mode without a target Set owner and repo on the GitHub connection.
scoring config: ... PULSE_SCORING_CONFIG is unreadable or invalid, or the profile is unknown Fix the file or the profile name.

The one-line audit

On the audit card Cause Fix
"…" is not a domain (expected something like example.com) You gave an IP address, localhost, or something that is not a host name Type a public domain, for example Audit example.com.
Nothing happens; the assistant answers in chat instead The line has a question mark, or no verb it recognizes Write Audit example.com, with no ?. See Audit a domain.
Waiting for the model (position N in the queue) Another audit's model calls are ahead of yours Nothing. Your steps run in turn.
Publishing schedule is skipped: no draft to put the plan's times on The plan had no draft to carry its dates Expected. The tasks are on the 90-day plan; the audit is not partial because of it.
A post in the Scheduled column of Campaigns says missed Its time passed while the piece was waiting for approval Reschedule it, or remove it. A missed post is never sent late.
A step is skipped with blocked: … A step it needs did not finish, for example blocked: the site could not be read (…) Fix the first failed step, then Resume the audit.
A phase reads … — not completed within the 3-minute budget The diagnosis has a time limit. A phase that did not finish inside it is reported as not done rather than left to look finished Expected under load. Run it again when the inference server is quieter.
diagnosis: … or the analysis was written but no plan was produced The model returned nothing usable, or the plan step failed Resume the audit. Steps already done are not repeated.
every lead discovery search failed (…) — the web was not reached No lead search answered Check the server's web access, then resume.
this domain was audited at … UTC (less than 24h ago) — returning that run A finished audit of the domain is less than a day old Use Run it again to force a fresh one.
PermissionDenied when you start an audit Your role is viewer Ask an admin to make you an editor.

The app looks empty

PULSE never fills a gap with an estimate. A figure it could not read is drawn as —, and a page with nothing behind it reads as empty rather than as a row of zeros. An empty page is usually a missing input, not a fault.

  • Brand Analysis says "No check-up yet", and its cards say "Not checked yet". Choose New site audit. See Getting started.
  • Results read "Not measured". Nothing measured the period yet. Connect Google Analytics, Google Ads or Search Console in Settings → Integrations. The work PULSE did is still counted, under What PULSE did. See Results and reports.
  • "Results of your posts: not measured yet". No platform reported results for your posts this week: connect Instagram, LinkedIn or YouTube, or wait for the first results after a post goes out.
  • Campaigns has no drafts, and Leads has no tasks. Run a check-up. A finished check-up fills them.
  • A card shows — where you expected a number. PULSE could not read that figure — usually a connection that is not set up, or a run that has not happened yet. Nothing is wrong with the card. See Measured and not measured.
