Configuration reference

Configuration reference

PULSE is configured through environment variables. This page lists the ones the backend reads, grouped by purpose. It names variables and describes their effect. It does not show values: secrets come from the secret store, and Runink's TIDDE platform sets the rest.

Command line

Command Meaning
pulse-server serve Starts the backend.
--port, -p The port to listen on. Defaults to PORT when set, otherwise 0, which picks a free port.

Server

Variable Effect
PORT Default for --port.
PULSE_WEB_DIR Retired. The backend serves no web bundle and the image no longer sets this. The production CORS check still skips when it is non-empty, so leave it unset. PULSE ships as an Android app (iOS planned, not yet built).
CORS_ALLOWED_ORIGINS Comma-separated origins allowed to call the API cross-origin. Unset means * outside production. In production it must be set to pinned origins with no wildcard, or the backend refuses to boot. Only an exact listed origin gets credentials.
PULSE_ENV production (any case) turns the insecure-configuration warnings into a refusal to start. Set by Runink on production deployments. No billing or plan behavior reads it. See Operations.
PULSE_GRPC_REFLECTION true turns on gRPC reflection. Off by default. For local work only.
PULSE_RATE_RPS, PULSE_RATE_BURST Per-caller rate limit, keyed by peer IP. Off unless PULSE_RATE_RPS is above zero.
PULSE_PUBLIC_BASE_URL The public https origin. The base of every sign-in redirect (/oauth/social/callback, /oauth/search-console/callback, /oauth/mail/callback), of the signed /media/ links Instagram fetches, and of absolute podcast-feed links. See Public address and redirects.
APP_VERSION The version stamped on log lines.
FEATURED_MESSAGES_PATH The file behind the featured-message strip.
A2A_ORGANIZATION The organization named on the A2A agent card. Falls back to RUNINK_ORG, then TIDDE_GITHUB_ORG, then empty.
SELF_HEAL_AUTONOMOUS false (or another no) turns automatic self-healing remediation off; plans are still recorded. Default: on. See Operations.

Security

Variable Effect
PULSE_JWT_SECRET Required. The key that signs and verifies every session. There is no default. It must never be a value that has been committed anywhere.
TIDDE_ENVELOPE_KEK Required. The key that seals OAuth tokens in PULSE's store. The store refuses to open without it.
SECRET_BACKEND Where secrets are read from. file reads each one from SECRETS_DIR/<name>; any other value reads the process environment.
SECRETS_DIR The directory the file backend reads. Default /var/run/secrets.
PULSE_TLS_CERT, PULSE_TLS_KEY In-process TLS for direct exposure. Set both or neither. TLS 1.2 minimum, forward-secret AEAD suites only.
MESH_MTLS true requires mutual TLS on the listener, with rotating certificates from the shared mesh CA. Takes precedence over PULSE_TLS_*. TLS 1.3 only.
MESH_CA_CERT, MESH_CA_KEY The mesh CA, from the secret store. Needed when MESH_MTLS=true.
MESH_ISSUER_URL, MESH_ISSUER_TOKEN_FILE The preferred mesh identity: the pod makes its own key and enrols it with TIDDE's mesh issuer, authenticated by the projected ServiceAccount token in the file. MESH_CA_CERT is then only the trust bundle and MESH_CA_KEY is not read. Without MESH_ISSUER_URL, the older shared-CA path (MESH_CA_CERT + MESH_CA_KEY) still works and logs an error on every start.
MESH_ADVERTISE_IP, MESH_ADVERTISE_HOST Extra IP and DNS names on the mesh certificate.
LICENSE, LICENSE_FILE, LICENSE_PUBLIC_KEY An offline licence, inline or as a file, and the key that verifies it. With no licence there is no gating.

Sign-in and users

Variable Effect
PULSE_ADMIN_PASSWORD (or ADMIN_PASSWORD) Seeds the break-glass admin. Without it, no password login exists.
PULSE_ADMIN_USERNAME, PULSE_ADMIN_EMAIL Overrides the break-glass admin's username (admin) and email.
GOOGLE_CLIENT_ID The Google OAuth client. Without it, Google sign-in is off.
OIDC_ISSUER Overrides the token issuer that Google sign-in trusts.
AUTH_GOOGLE_ONLY true hides the password form.
AUTH_ALLOWED_EMAILS The Google sign-in allowlist. Empty means nobody signs in with Google.
AUTH_SEED_USERS Operator-granted roles as email=persona,…. Applied at every start.
PULSE_CLIENT_INSTANCE, PULSE_CLIENT_INSTANCE_NAMESPACE Set by Runink: which deployment this is, so the Admin page can write member changes back to the platform.
GOOGLE_CLIENT_SECRET The Google OAuth client's secret: Connect with YouTube, Search Console and Gmail, and token refresh. See Google.
GOOGLE_TOKEN_ENDPOINT Overrides Google's token endpoint (tests).

See Users and access.

Storage

Variable Effect
PULSE_DATA_DIR Scratch directory (renders, clones). Nothing durable is kept there. Default ./data.
PULSE_APPFS_BUCKET Bucket of the sealed app root on the object store: every table, account, session and media file. Default pulse; the TIDDE platform sets it.
PULSE_APPFS_DIR Local sealed app root when there is no object store. Default $PULSE_DATA_DIR/appfs.
OBJECTSTORE_ENDPOINT, OBJECTSTORE_ACCESS_KEY, OBJECTSTORE_SECRET_KEY The object store the app root is mounted on (the platform's object store).
OBJECTSTORE_BUCKET The object store bucket.

Inference

Variable Effect
INFERENCE_REMOTE_URL Use the shared inference plane at this address: the platform's model router in your deployment.
INFERENCE_MODEL The model name PULSE asks the inference plane for. Unset, PULSE uses the platform default. In a cluster the name is only a label.
INFERENCE_API_KEY Key for the inference server.
MODEL_VISION, VISION_REMOTE_URL The vision model that describes photos and video frames attached to an audit, and where to send them. off turns it off. Without it, attached photos are marked "image understanding unavailable".
PULSE_JUDGEMENT off disables the plan gate.
PULSE_EGRESS_ALL_AGENTS Widens output screening to every agent. Screened answers arrive whole instead of streaming.
TIDDE_HEALTH_URL Where agent health reports go. Unset means no reports.

See Sovereign inference.

Connections

Each person connects their own accounts under Settings › Integrations. These are the instance's app clients that make one-click sign-in possible; all are secrets from the instance's secret store.

Variable Effect
META_APP_ID, META_APP_SECRET Connect with Instagram. See Meta.
LINKEDIN_CLIENT_ID, LINKEDIN_CLIENT_SECRET Connect with LinkedIn. See LinkedIn.
LINKEDIN_COMPANY_PAGES true once LinkedIn approved the Community Management API: offers company pages.
MICROSOFT_CLIENT_ID, MICROSOFT_CLIENT_SECRET, MICROSOFT_TENANT_ID Connect Microsoft 365 (tenant default common). See Email.

GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET (under Sign-in) serve YouTube, Search Console and Gmail too.

Site audit and scoring

Variable Effect
PULSE_SCORING_CONFIG A JSON file overlaid on the built-in scoring config.
PULSE_SITE_AUDIT_URL The site the daily audit engine checks. Falls back to PULSE_SITE_BASE_URL. The engine also needs PULSE_APPLY_ENABLED=true before it starts.

Weekly learning

Variable Effect
PULSE_RESULTS_PLAN_WINDOW_DAYS, PULSE_RESULTS_PLAN_MIN_EVIDENCE The weekly results review: how many days of results it reads, and how many outcomes one row needs before it may propose a change. Whole numbers above zero. Unset or invalid means the review proposes nothing. Each account still switches the review on itself.
PULSE_MARKET_MEMORY_WINDOW_DAYS, PULSE_MARKET_MEMORY_MIN_EVIDENCE The weekly market learning: how many days of results it reads, and how many outcomes one row needs before anything is remembered from it. Whole numbers above zero. Unset or invalid means it learns nothing. Each account still switches it on itself.
PULSE_ADVISOR_WINDOW_DAYS, PULSE_ADVISOR_MIN_EVIDENCE The weekly growth advisor: how many days of results it reads, and how many outcomes one row needs before an option may rest on it. Whole numbers above zero. Unset or invalid means it suggests nothing. Each account still switches it on itself.

Publishing

Variable Effect
PULSE_APPLY_ENABLED The global kill switch. Only the exact value true arms anything.
PULSE_PUBLISH_<CHANNEL> Narrows one channel: BLOG, PODCAST, AUDIOBOOK, YOUTUBE, INSTAGRAM, SPOTIFY, LINKEDIN, EMAIL, WHATSAPP, SMS, and the reply keys LINKEDIN_REPLIES, INSTAGRAM_REPLIES, INSTAGRAM_DMS, YOUTUBE_REPLIES.
PULSE_PUBLISH_AUTOMATIONS Lets automations do outbound work. Off by default.
PULSE_EMAIL_DAILY_LIMIT Emails one person may send per 24 hours. Default 50.
PULSE_OPPORTUNITIES_DISCOVERY The daily read of open procurement data. On by default.
PULSE_PUBLISH_CONFIG_PATH, PULSE_PUBLISH_CONFIG_JSON The per-channel arming file, or the same JSON inline.
PULSE_PUBLISHER_USER_IDS Comma-separated PULSE user ids allowed to publish through the deployment-global channels (LinkedIn, blog, podcast, audiobook). Empty means nobody.
PULSE_AUDIT_APPLY Arms the audit-fix modes of ApplyAuditActions (apply/commit/pr), on top of PULSE_APPLY_ENABLED=true. Off unless an explicit yes. Admins only.
PULSE_APPLY_ROOT The only directory an audit-fix repo_path may resolve into. Unset refuses every mode, plan included.
PULSE_SITE_REPO, PULSE_SITE_BRANCH, PULSE_SITE_BLOG_DIR, PULSE_SITE_PUBLISH_MODE, PULSE_SITE_AUTHOR, PULSE_SITE_BASE_URL Blog publishing to your website.
PULSE_GIT_AUTHOR_NAME, PULSE_GIT_AUTHOR_EMAIL The author on commits PULSE makes.
YOUTUBE_PRIVACY_STATUS public, unlisted, or private. Unset means private.
LINKEDIN_ACCESS_TOKEN, LINKEDIN_AUTHOR_URN, LINKEDIN_API_VERSION The deployment's LinkedIn token (from a secret) and author (person or organization URN), used only for a user with no LinkedIn connection; and the API version header.
LINKEDIN_API_BASE Overrides LinkedIn's API base (tests).
PULSE_LINKEDIN_CTA_URL The link the daily LinkedIn draft ends with. Default https://runink.org.
PULSE_PODCAST_TITLE, PULSE_PODCAST_DESCRIPTION, PULSE_PODCAST_LANGUAGE Podcast feed metadata.

The defaults and the safe order to turn these on are on Switches and arming order. See Publishing controls and Site pipeline.

Media

Variable Effect
PULSE_SHORTS_ENGINE Default on. Exactly off stops the daily short-video draft for every account (the kill switch). Each account also switches the draft on for itself in Settings › Account (default off); see Short videos.
PULSE_SHORTS_DAILY_CAP How many short-video drafts one account gets a day (0 to 10). Default and fallback 1.
PULSE_VOICEOVER_MAX_PARALLEL How many voice-overs the server speaks at once, for all accounts together (1 to 4). Default and fallback 1: the speech service is shared GPU capacity, so a job waits as "queued" for a free slot. Each account still has one voice-over being made at a time. A voice-over is a kept job that goes on when the app is closed; a server restart marks the ones it was making as interrupted, and the person tries them again.
FFMPEG_PATH Overrides the ffmpeg binary for the audiobook assembler. Short videos use the server's own video tool, which is checked when the server starts: if the check fails no video is made, and /health says so.

Telephony and messaging

Variable Effect
PULSE_OUTBOUND_CALLS One of the switches an AI call needs (with PULSE_AI_CALLS). Off by default. Callers must also be editor or admin.
TWILIO_ACCOUNT_SID, TWILIO_AUTH_TOKEN The carrier account behind WhatsApp, SMS and Send / Call. Both are secrets.
TWILIO_WHATSAPP_FROM, TWILIO_FROM_NUMBER, TWILIO_VOICE_FROM The WhatsApp sender, the SMS number, and the number calls are placed from. TWILIO_VOICE_FROM is optional and falls back to TWILIO_FROM_NUMBER.
PULSE_WHATSAPP_USER_ID Which user's HubSpot connection backs the WhatsApp sender allowlist, and as whom replies run.
PULSE_WHATSAPP_AUTOREPLY true turns automatic WhatsApp/SMS replies on; they also need PULSE_APPLY_ENABLED=true and PULSE_PUBLISH_WHATSAPP / PULSE_PUBLISH_SMS. Default: off.

See Telephony and messaging.

Billing and tenancy

Variable Effect
TENANT_ID This deployment's tenant.
SUBSCRIPTION_TIER, SUBSCRIPTION_SEATS, SUBSCRIPTION_STATUS The subscription the Billing page shows.
SUBSCRIPTION_PERIOD_END The current billing period's end (RFC 3339).
RUNINK_ACCOUNTS_FILE The member-to-purchaser file the TIDDE platform provides. Each signed-in person's plan and seats come from the purchaser it names.
RUNINK_USAGE_* The usage bucket the TIDDE platform provides.
TIDDE_ROUTER_BILLING_KEY_FILE, TIDDE_ROUTER_BILLING_KID The service key file and key id PULSE signs its model-router billing claim with. Unset, model calls carry no claim and the router treats them as spot work.

Usage is kept on the object store configured under Storage. See Billing and Plans.

Names that are no longer read

Some variables of earlier releases are read by nothing now. Setting one does nothing, and PULSE does not warn: a deployment that still sets only an old model variable runs on the default model. The list is under Old names and addresses. Use INFERENCE_MODEL and INFERENCE_REMOTE_URL.
