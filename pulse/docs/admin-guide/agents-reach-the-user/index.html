Agents that reach the user

Agents that reach the user

When PULSE's assistant cannot answer from the account's own data, it can ask the account's owner one short question. The owner answers in the app or by replying to a message on their own phone. Everything is off by default.

What the owner sees

  • Settings › Account › Agents that ask you: the open questions with an answer box and Dismiss, and the switches.
  • The bell shows "An agent has a question for you" while one is open.
  • A question is always shown in the app. It needs no carrier.

When a message goes to the phone

A message (SMS or WhatsApp) goes out only when the owner has opted in and an administrator has set up messaging. If a message is not sent, the reason is written on the question ("Not sent as a message: why") and the question stays in the app.

  • Opt-in. Agents may message me on my phone is on (default off). The person picks one of the contacts an administrator added in Admin › Messaging; a lead is never offered.
  • Approval. The assistant proposes the question as a card the person confirms, like every assistant action, unless the person has switched on Don't ask me first each time (off by default, revocable).
  • Quiet hours. The person chooses them.
  • Administrator switches. The carrier is configured (Admin › Messaging) and PULSE_APPLY_ENABLED with PULSE_PUBLISH_SMS or PULSE_PUBLISH_WHATSAPP are armed. These are the same switches every message uses.
  • Pause. An administrator can pause questions in Admin ("paused by your administrator").

SMS is the default channel; WhatsApp only accepts a business-initiated message inside its own messaging window. A refusal leaves the question in the app with the carrier's reason.

Calls are not part of this. The one call path stays PlaceAICall.

Replies

Point the Twilio "A message comes in" webhook of the SMS sender at /comms/twilio/inbound; the WhatsApp edge (/twilio/message) is wired too. A reply to the message is attached to the question. A reply of STOP closes the question and switches the opt-in off. The answer is removed with the account.
