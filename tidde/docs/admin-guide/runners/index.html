Runners

Integrations › Runners

A data-access runner is the process that reaches a data source on TIDDE's behalf. It is not a CI runner. The page is Settings › Integrations › Runners (?tab=runners).

Warning: Estate actions run on the Runink managed runner (console). A self-hosted runner can be added and reports its health, but an action routed to it is answered runner_offline, and nothing runs. Choose console for the action.

The two kinds

Kind What it is
Runink managed (console) the console itself. It is always there and cannot be revoked.
Self-hosted a tidde-runner process on a host you run, under the name you gave it

Add a self-hosted runner

You need to be on the runner-admin list (when the list is not set, every signed-in operator may).

  1. Add the runner

    Choose Add runner and give it a name, its address, and optionally a zone and labels. It starts PENDING.

  2. Start tidde-runner on its host

    Follow the instructions the page shows for the new runner.

  3. Check its state

    Once the runner is connected it shows ACTIVE, with its health as the runner reports it.

Operate a runner

Action What it does
Edit address changes where TIDDE connects; recorded in the audit chain
Revoke runner TIDDE stops using it

Choose the runner for an action

Every estate action can name a runner: none (use the connection's own runner, by default console), console, or a runner's name. The choice is recorded in the audit chain.

Refusal Meaning
runner_unknown no runner of that name
runner_revoked the runner was revoked
runner_offline the runner is not available for the action

None of them reaches a data source, and none falls back to another runner.

Runners TIDDE deploys

TIDDE can also deploy a runner for you on an on-premise host, on Google Cloud, on Snowflake, or on Databricks. Choose Deploy and pick the target. Deploying needs the runner-admin list to be set and to name you. A deployed runner can be redeployed or decommissioned.

What a runner never does

It holds no source configuration and no stored credentials, and schedules nothing.
