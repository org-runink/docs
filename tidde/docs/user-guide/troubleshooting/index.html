Troubleshooting

Troubleshooting

Problems with signing in, with refused changes, and with reading the Overview. Messages are quoted as the console shows them, so you can search for them. For other areas see the troubleshooting page of DEVEX, DataEx, Intelligence and FORGE. Problems that need the installation's own configuration are for your installer, with the private install guide.

Signing in

Message What it means What to do
"… is not authorized for this console" Google signed you in, but your address (or domain) is not approved. An empty list refuses everyone. Ask your instance admin to add you, or Runink to add an admin. Creating an account on the sign-in page does not give access.
"Sign-in is unavailable: this console cannot open its session store … Your credentials were not the problem — tell an operator." the console cannot reach the store that keeps sessions tell your installer; sign-in retries on its own
"Invalid username or password." the break-glass sign-in was used with a wrong credential; the attempt is recorded use Google sign-in
"password sign-in is not configured" the break-glass sign-in is off on this installation use Google sign-in
"csrf check failed" the sign-in form lost its cookie on the way reload the sign-in page and try again; check nothing strips cookies
"Sign-in failed. Try again." the Google token did not verify (wrong client, wrong issuer, or an unverified email) sign in with a verified Google address; if it persists, tell your installer
"sign-out could not revoke your session on the server; it expires on its own — tell an operator" the session store could not be written the session still ends after 12 hours
every request answers unauthorized your session expired or was ended sign in again; the console returns you there on its own

Refused changes

Message What it means What to do
"… is not permitted to … on this console (…)" you are signed in, but the write list for that change does not name you; the list is named in brackets ask an admin to add you. DataEx › Harness (Access) shows which lists are set and whether you are on each
"this console has no sign-in configured, so … would be unattributable" the installation has no sign-in method, so no change can be attributed tell your installer
"this console has no sign-in configured, so nobody can be shown the audit trail — …" same cause, when reading the audit chain on DEVEX › Agent runs. With sign-in configured, reading it also needs the session-admin list, and an unset list means nobody ask an admin to add you to the session-admin list

The edge in front of the console

Message What it means What to do
auth: <email> is not permitted your account is not on the edge's allowlist ask your admin
auth: sign-in is unavailable (no session store) — tell an operator the edge cannot keep sessions tell your installer
auth: state expired the sign-in round trip took too long start again
auth: token exchange failed the identity provider did not complete the sign-in try again; if it persists, tell your installer

Reading the Overview

What you see What it means
A red notice under the header, and the cluster source marked absent the console could not read a namespace it tracks; the notice gives the first error. An unreadable namespace is never drawn as healthy.
Agent runs (7d) and Success rate show "—" with "Install the Runink TIDDE GitHub App …" the console cannot read CI runs; it is not zero runs
Success rate shows "—" with N ok · M failed no run in the window has finished yet
Client instances is neutral (not green) there are no instances: nothing to judge is not a pass
The pill says 4/5 healthy one tracked workload has fewer ready replicas than desired. Open DEVEX › Clusters (Namespaces section).

Navigation

Symptom Cause
A ?tab= link opens Overview the name is not a live or retired tab name; see the console map
The Admin row is missing the rail shows it only when the server says you are an admin of the chosen instance. Drill into an instance from the Overview's bird's-eye first.
