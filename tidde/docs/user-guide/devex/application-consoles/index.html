Clusters (Overview section)

Clusters (Overview section)

DEVEX › Clusters (Apps and agent planes section) (?tab=appConsoles, the Application consoles row until 2026-10-31) is the first tab of Clusters: a door grid with one card per tool you may reach: what the tool is for, whether it is up, and how to open it (GET /api/app-consoles). A card does not repeat the ready/total count: that is Namespaces' and the Clusters header's. A count that could not be measured still says so on the card.

Who sees which cards

The server decides, not the page:

Viewer Cards
an installation admin every tracked cluster namespace's tool, every application control plane, and every instance
everyone else only the instances where they hold a live role; never a cluster card or a control plane

What a card says

  • What it is for: one sentence per tool.
  • Health: the same verdict Clusters (Namespaces section) shows for that namespace, so the card and the page cannot disagree. A namespace whose workloads could not be read is never shown as healthy; it says unmeasured with the reason.
  • Open: either the console page that is the tool's control surface (for example Clusters (Namespaces section) on that namespace), or the tool's own host in a new browser tab. An instance's Open asks the server for a member-only entry ticket first (GET /api/instances/open).
