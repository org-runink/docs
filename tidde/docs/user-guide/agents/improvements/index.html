Improvements

Improvements

AGENTS › Improvements (?tab=improvements) is where TIDDE tells you what it changed about itself, and lets you ask for it to be undone.

Status: built; it has not run yet. The page is in the console, and until the first improvement happens its timeline is empty.

Section What it shows
What TIDDE did on its own a timeline of every self-improvement action
Recent notices the notices TIDDE sent about those actions
How you are told how notices reach the platform admin: always in the console, and by message when a channel is configured

What you can do

  • Set the limits for self-improvement: Off, Dry run, and a daily cap. Self-improvement is off until an agent admin turns it on.
  • Request a revert of any action (agent admins).
  • Save how you are told.
