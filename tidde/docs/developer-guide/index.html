Developer guide

Developer guide

The Developer guide is for building on TIDDE: its APIs, its command-line interface, FORGE's MCP tools, and the contracts the agents use.

  • HTTP route reference: Every console route and how each class is authorised.
  • DataEx API: Agents, harness, judgements and runner routes.
  • Intelligence API: The gRPC-web services: estate and Ask.
  • FORGE API: The FORGE studio's services and capabilities.
  • MCP tools: The tools FORGE and the agents call, including the knowledge-graph tools.
  • CLI reference: The tidde command.
  • Agents in CI: How the review, fix and audit agents run on a Git host.

The services

The console serves JSON routes under /api/* and gRPC-web services on one origin and one session:

Service Purpose
AskService grounded Ask TIDDE answers
EstateService data estate sources, explore, map, and declared-versus-observed reconciliation
OpsDoctorService the ops doctor's repair preview and approval
EvidenceService deployment-evidence harness runs and publishing
RunnerBootstrapService, RunnerService registering a data-access runner, and the runner's own service
ChatService, ProjectService, IdentityService, ForgeService FORGE: chats and projects (one chat is one project), identity, studio operations

TIDDE also serves the shared Runink services the console pages use: access, billing, chat, profile, voice, reasoning, estate, data sources (connections, listeners, runners) and judgement.

The data model

The tenant API is the ClientInstance resource; its fields are on Architecture. The console keeps each store (agent health, schedules, runs, lineage, findings, judgements, plans, connections, subscriptions) as a table in its own encrypted root, and every write is recorded in a hash-chained audit trail that GET /api/audit/verify checks.

Building on TIDDE

  • Script the console with the tidde CLI or the HTTP routes, using a console session.
  • Register connections from a manifest with tidde connection register; see Integrations.
  • Call FORGE's MCP tools over JSON-RPC at POST /api/forge-mcp; see MCP tools.
  • Report to TIDDE from an agent through the ingest routes in the DataEx API; an admin issues the ingest credential.
