On-device model

On-device model

Note: Status: built, not yet available in a store. The model comes with the Android app: it is installed together with it, about 392 MB. If it is missing (a test build made without it), the app says the on-device model is not available rather than answering.

What it does

The on-device model gives Luna's chat replies on your phone:

  • On the free tier, it is how Luna chats. Replies are shorter than on the server model.
  • When the connection is lost, the app uses it so the conversation can go on.

What it reads

Your message. The model runs entirely on the phone, and no server model is asked to answer it.

What it produces

A short chat reply, as text or read aloud by the phone's own voice.

What it will not do

  • No health answers. Health questions wait for a connection. Luna says so ("On the free plan I answer from this phone, and I don't answer health questions from it. Please ask a professional."; offline: "Ask me again when you are back online.").
  • Care first. If a message suggests you may be in danger, the app shows its fixed supportive message, which points to emergency services and a crisis line, instead of a model answer.
  • No actions. It only writes a reply. It does not save plans, change your data or act outside the phone.
  • No photos, documents or plans. Those need the server model (paid plan, coming).

Model

Qwen3-0.6B, an open model from the Qwen team (Apache-2.0), made smaller (4-bit) to run on a phone. It is far smaller than the server model.

Where it runs

On your phone (Android first; the iOS app has never been compiled). It is not available in the web test build.

Scope

  • It is a smaller model than the server model: expect shorter and simpler answers.
  • Like every part of Luna, it is not a medical, mental-health or emergency service. See Safety.
