Admin guide

Admin guide

LUNA is a personal app: one person, one account, one phone. There are no workspaces, teams, roles, shared data or settings console, so an admin has very little to do in LUNA, and most of it is done by Runink on request. This page says what there is.

Who can sign in

  • Approved accounts only. There is no open sign-up and no self-invite. Runink approves each Google account; nobody else can sign in.
  • Google Sign-In is the only way in. There are no passwords.
  • Admins are added by Runink. An admin cannot add other admins or approve accounts from inside the app.

What an admin gets

An admin named by Runink is never limited by the free tier: no 14-day read-only limit and access to the server features. An admin must also be an approved account; being named an admin does not let anyone sign in.

Plans and trials

Every approved account starts on the free tier: the on-device model, no evolution, and read-only 14 days after the account is created. A paid plan is coming and cannot be bought yet. Plan and trial state are set by Runink, not in the app. For prices, see the product page at runink.org. Details: Free tier and paid plan.

Removing access

Ask Runink to remove an account's approval. Every session of that account ends at once. The account's data stays in place until a deletion request.

Data requests

Deletion is on request: ask Runink, as the privacy policy describes. See Privacy and data.

Settings a person controls

Everything else is set by each person on their own phone: data connections (steps, body, sleep, weather), gentle reminders, companion tone, the form or companion, and the speaker toggle. The app language follows the phone.
