Sovereign inference

Sovereign inference

FACE calls no outside AI service. Every model request FACE makes for text, vision and speech recognition goes to the inference plane the deployment configures, a mistral.rs server run by the platform. Prompts, fetched records and model answers never go to a model vendor.

How inference is wired

  • One endpoint. All text generation, vision grading and agent reasoning are HTTP calls to the inference plane. The base URL comes from one deployment setting, the only one FACE reads for it. The vision and voice tiers can be pointed at their own endpoints. When those are unset, both fall back to the main endpoint.
  • No bundled model server. FACE ships no inference binary and starts no model-server child process. It has no local "fallback" model tier.
  • Inference is required to start. If the inference endpoint is unset or blank, the backend refuses to start with an error saying no inference endpoint is configured. If a call reaches a model client with no endpoint, it fails with FailedPrecondition naming the missing setting, rather than a transport error that names nothing.
  • An authenticated plane. FACE presents the configured service token to the plane. It never generates a token of its own.
  • Internal-only model service. FACE's own ModelService gRPC door, which its agents use to reach the plane, accepts only this process (loopback plus a verified mesh certificate). The one method the app calls, GetModelStatus, says only whether inference is ready and needs a session. See Identity & access.
  • Speech. Phone-call transcription is a request to the plane's voice tier. Speech synthesis runs in process with a bundled local engine (Piper), so generating audio does not leave the pod.
  • No LLM vendor SDK. FACE's Go module does not depend on any LLM vendor SDK, and the backend uses no LLM orchestration framework.

What sovereign means for data egress

Keeping inference in the cluster removes the largest egress path an AI product usually has. It does not mean FACE never talks to the outside world. These are the paths that can leave your network, and each one exists only if you configure the feature behind it:

Path What leaves When it exists
Data-source connectors Queries and API requests to the source systems you connect: warehouses, ERPs, logistics APIs, devices. For each connection you create. The destinations are governed by the connector address policy.
Web search and page reading Search terms and page requests to the public web, fetched through a headless browser. When an agent or the FACE app uses web search or reads a web page.
Maps and routing Nothing. FACE calls no map, places, geocoding or routing service: routes are computed in the cluster, basemap tiles are served by FACE itself, and place lookups are ordinary web search (the row above). Never.
Single sign-on Token verification against your OIDC issuer. Only when single sign-on is configured.
Email Drafts the twins agent creates in a connected mailbox. A person reads and sends them; mail a model composes is never sent without a person. Only with a connected mailbox (see AI safety).
Telephony and messaging Call audio and messages carried by the telephony provider, Twilio. Only when the voice line or messaging is configured.

Everything a model reads (fetched rows, page text, call transcripts) is processed by that inference plane. The table above lists the only routes by which data leaves.

Warning: Scope of these controls

  • A configured endpoint is not a reachable plane. The startup check confirms that the inference endpoint is set. It dials nothing, and it does not prove a model is loaded.
  • Sovereignty depends on where the plane runs. FACE sends inference to the URL it is given. That the URL points at a plane the platform runs, and not at an outside service, is a deployment fact, and you have to verify it on your own installation.
  • Voice calls go through a carrier. A phone call's audio travels through the telephony provider before it reaches FACE. Transcription and reasoning are sovereign, but carriage of the call is not.
