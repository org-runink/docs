Troubleshooting

Troubleshooting

FACE tells two situations apart. It could not look: the request failed, so nothing is known. Or it looked and found nothing: the answer came back and was empty. The messages below are the exact English wording. Check which of the two a message describes before you act on it.

Signing in

Message What it means What to do
Single sign-on is unavailable — the sign-in service could not be reached. You can still sign in with your email and password. The app could not reach the sign-in service's configuration. Sign in with your email and password, or try again later.
The server did not accept these credentials. The email or password was rejected. Check both and try again.
Invalid two-factor code The code from your authenticator was wrong or out of date. Wait for the next code and enter it.
MFA session expired — please sign in again The second-factor challenge timed out. Sign in again from the start.
This account is not authorized for this instance Your account is valid but has no access to this instance. Access is granted by Runink: ask your Runink contact or your FACE administrator. See Access and the trial.
Session expired — please sign in again Your session ended. Sign in again.

No data yet

Message What it means What to do
Nothing is connected yet No data source is attached to this instance, so there is nothing to assess. Add one under Settings › Integrations › Systems.
No data source is configured yet. The source list was read and is empty. Select Connect a data source.
Could not load your data sources. The source list could not be read. Select Retry.
Your operation's story starts with a fetch No run is selected, so the page has nothing to show. Ask a question on Ask, or select Open an earlier run.
Run a fetch first — the compliance twin analyzes that instance’s real findings, not a blank prompt. The remediation screens analyse a run's findings, and none has finished yet. Run a question on Ask first.
Unable to Assess The twin answered, but could not produce an assessment. This is not a clean result. Read the summary for the reason. Usually you need to connect a data source and run again.

Ask

Message What it means What to do
Switched off: not read by Fetch An admin switched this connection off, so no run reads it. Ask an admin to switch it back on, under How FACE knows this on Ask.
{name} was not switched: {error} The Active switch could not be saved. Read the reason. Only an admin can switch a connection or runner.
Offline mode: Fetch task queued for background synchronization. The app could not reach the server, so it kept the run on your device. Nothing. The run is sent when the connection returns.
Offline queueing failed: {error} The run could not even be queued. Try again once you are back online.
No result received The run ended without a final answer. Open the run to read what arrived, then ask again.
Your last fetch failed. The last run did not complete. Select Open the run and read Result and Error.
Your last fetch answered, but not every phase finished. The answer came back, and a phase after it did not finish. The message names which, and why. Pages that phase feeds say so for this run. Ask again, or open an earlier Successful run.
Failed to load fetch starters The prepared questions could not be loaded. Type your question instead.
This run is no longer in your history. The run was deleted from this device. Run it again.

Options, Why and Actionable Twins

Message What it means What to do
Failed to fetch action queue: {error} The decisions on Actionable Twins could not be read. The list may not be empty. Select Refresh.
The map could not be loaded: {reason} The Map view could not read where your assets are. Read the reason, then open the Map view again.
Live layers could not be read: {reason} The map's live connection layers could not be read. Your own assets may still show. Check the connections are active, then open the Map view again.
That file is too large to analyze (3 MB maximum). The file for Analyze document is over the limit. Split or reduce the file.
Could not read that file. The browser could not read the chosen file. Pick the file again.
Could not load scenarios The scenarios could not be read. Select Retry.
Failed to extract rules: {error} The rules could not be read. Select Retry on Why.
The options could not be compared: {error} Options could not compare the options for a decision. Nothing is shown in their place. Try again.

Automated analysis

Message What it means What to do
Automated analysis is starting up… The analysis models are loading. Everything else works now. Wait, then select Check again.
Automated analysis is not ready — features that need it are unavailable. The analysis service cannot answer. Select Check again. If it persists, see Operating FACE.

Voice

Message What it means What to do
Voice input is unavailable in this browser or the microphone was blocked. Type your question instead. The browser has no speech support, or microphone access was refused. Allow the microphone for FACE's site in your browser settings, or type instead.

Still stuck

For problems on the deployment side, see Operating FACE.
